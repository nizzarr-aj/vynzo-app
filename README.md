# VYNZO

واجهة أولية لتطبيق فيديوهات قصيرة باللغة العربية، مبنية بـ React + Vite ومتصلة بمشروع Supabase.

## الموجود حاليًا
- إنشاء حساب وتسجيل الدخول عبر Supabase Auth.
- لوحة رئيسية تعرض النقاط والقيمة التقديرية من `vynzo_wallet_summary`.
- عرض حالة الصندوق الذهبي عبر `vynzo_golden_box_status` واستلامه عبر `vynzo_claim_reward_box`.
- صفحة فيديوهات تقرأ من `vynzo_video_feed` وتعرض الفيديو إذا كان `video_url` رابط HTTP(S) قابلًا للوصول.
- واجهة عربية RTL متجاوبة مع الهاتف.

## التشغيل المحلي
1. ثبّت Node.js (إصدار LTS).
2. انسخ `.env.example` إلى ملف اسمه `.env`.
3. عبّي متغيرات البيئة:
   - `VITE_SUPABASE_URL`: رابط مشروع VYNZO.
   - `VITE_SUPABASE_ANON_KEY`: مفتاح Supabase publishable/anon فقط.
4. نفّذ:
   ```bash
   npm install
   npm run dev
   ```
5. للبناء:
   ```bash
   npm run build
   ```

**مهم:** لا تضع مفتاح `service_role` في تطبيق الواجهة أو في GitHub.

## النشر على Vercel
- اربط المستودع `nizzarr-aj/vynzo-app` في Vercel.
- Framework preset: Vite.
- Build command: `npm run build`.
- Output directory: `dist`.
- أضف متغيري البيئة السابقين في إعدادات المشروع، ثم أعد النشر.

## ما لم يكتمل بعد
- اختبار بناء فعلي وتشغيل على جهاز/متصفح.
- رفع الفيديوهات وتشغيل ملفات التخزين الخاص عبر signed URLs.
- تفعيل تبويبي المكافآت والمحفظة كصفحتين مستقلتين.
- الدفع الحقيقي لشراء النظارات، نظام مراجعة السحب، ومكافحة الغش.
- وقت المشاهدة الحالي يحتاج تحققًا موثوقًا من جهة الخادم قبل ربطه بأي مكافآت نقدية.
- السحب والتحويل معطّلان في قاعدة البيانات؛ النقاط المعروضة ليست وعدًا بأرباح مالية.

هذه نسخة تطوير أولية وليست جاهزة للإطلاق التجاري أو لاستقبال مدفوعات.
